DISHUP — multi-country PLAYABLE PROTOTYPE, NOT 2,200 verified dishes.

World: 100 original dishes. Italy: 40 regional starters plus mapped originals. France, Spain, Japan, Mexico, India: small regional starter pools.

IMPORTANT: Newly added national dishes have PLACEHOLDER nutritional values and year 1900, flagged placeholderNutrition and placeholderYear. Do not publish these as factual. Replace them with researched values before public release.

Country maps: Italy via Openpolis, other countries via geoBoundaries public API; requires internet. If boundaries unavailable, fallback selector should appear. Region naming can vary across datasets; validate selections against region names before publishing.

The 1,000 World + 200 per country requested are NOT yet supplied. This package demonstrates working architecture, not a finished database.

To run: upload index.html, script.js, style.css together to GitHub Pages. Test all six countries.
